# MeGaComputers — Çay Evi / Restoran Satış Proqramı

Çayxana və restoranlar üçün sadə satış (POS) proqramı. Quraşdırma tələb etmir —
`index.html` faylını istənilən brauzerdə (Chrome, Edge, Firefox) açmaq kifayətdir.
İnternet lazım deyil.

## İmkanlar

- **Masalar** — masaların vəziyyəti (boş / dolu), açıq hesabın məbləği, "Paket (aparmaq)" sifarişi
- **Sifariş** — kateqoriyalar üzrə menyu, axtarış, say artır/azalt, endirim %, qeyd
- **Ödəniş** — nağd (qaytarılacaq qalıq hesablanır) və ya kart, çekin çapı (80 mm termal printer üçün)
- **Hesab çap et** — ödənişdən əvvəl müştəriyə hesabın çapı
- **Menyu** — məhsul əlavə etmək, redaktə, silmək, müvəqqəti deaktiv etmək
- **Hesabat** — tarix aralığı üzrə ümumi satış, nağd/kart, çek sayı, orta çek, ən çox satılanlar,
  çeklərin təkrar çapı, Excel üçün CSV ixracı
- **Ayarlar** — müəssisənin adı, ünvanı, masa sayı, xidmət haqqı %, çek altı mətn,
  ehtiyat nüsxə (JSON) yükləmək və bərpa etmək

## Qeyd

Məlumatlar brauzerin yaddaşında (localStorage) saxlanılır. Brauzer məlumatlarını
təmizləməzdən əvvəl və ya kompüteri dəyişməzdən əvvəl **Ayarlar → Ehtiyat nüsxəni yüklə**
düyməsindən istifadə edin.
